# Assets — RTS0 (Thronefall palette)

All runtime visuals currently **procedural** (`WorldView.cs` primitives) + **thronefall shaders** (`shaders/*`). This folder holds imported CC0 + project-generated textures/materials.

## Folder layout (mirrors 0ad `binaries/data/mods/public/art/` for familiarity)

```
assets/
  models/
    units/        ← human units (villager, swordsman, archer) — low-poly, <1k tris, rigged
    buildings/    ← house, town-center, barracks, etc — modular pieces (wall, roof)
    vegetation/   ← tree, gold-vein (trunk+leaves split for wind)
  textures/
    terrain/      ← splat weights, heightmap (generated or 2k png)
    noise/        ← terrain_noise.png (512×512 FastNoiseLite, used by terrain.gdshader)
  materials/
    thronefall/   ← unit.tres / terrain.tres / foliage.tres (ShaderMaterial → shaders/*.gdshader)
  sounds/         ← UI, gather, attack, build (ogg, 44.1k)
  fonts/          ← main UI font (e.g., Kenney Mini)
  imported/       ← **gitignored** — drop CC0 packs here before import (Kenney, Quaternius)
```

## Thronefall palette (used by shaders)

- Player `0.36,0.62,0.94` / Enemy `0.92,0.32,0.28` — `shaders/unit_thronefall.gdshader:3`
- Terrain `grass 0.55,0.72,0.42` / `dirt 0.62,0.55,0.45` / `rock 0.58,0.59,0.60`
- Fog `0.12,0.14,0.18` (matches `project.godot:environment/defaults/default_clear_color`)
- Flat ramp `flat_steps=3`, outline `0.012`, roughness `0.75`

## CC0 sources (Thronefall style, no license headache)

- **Kenney.nl** `Kenney Game Assets 1 / Mini Characters` — MIT/CC0, low-poly primitives compatible with our `CapsuleMesh`/`BoxMesh` scale
- **Quaternius.com** `Ultimate Low Poly Pack` — CC0, has villagers/buildings/trees that match scale `GameSim.Grid=2.0`
- **Optional paid:** Synty Studios POLYGON series (if budget)

> Drop `.glb` into `assets/imported/` → Godot imports as `assets/models/.../*.glb` + `.import` (keep `filter=false, fix_handedness`). Re-export via `tools/build.py` will bundle.

## Pipeline

1. **Procedural fallback:** `WorldView.cs:84` creates `CapsuleMesh`/`BoxMesh`/`CylinderMesh` when no `.glb` found → always builds even with empty `assets/`
2. **Shader-driven:** `WorldView` loads `shaders/*.gdshader` as `ShaderMaterial` + `INSTANCE_CUSTOM` (team/hp/wind) → one material per MultiMesh, no per-instance textures
3. **Noise:** `assets/textures/noise/terrain_noise.png` generated by `tools/generate_noise.py` (512×512, tiled). If missing, `terrain.gdshader` falls back to procedural `fract(uv)` grid
4. **Import settings:** `project.godot` `renderer/rendering_method="forward_plus"` + `msaa_3d=2` already; textures `s3tc_bptc` on desktop, `etc2_astc` on Android (`export_presets.cfg`)

## Adding a new unit model (example)

```bash
# 1. drop CC0 glb
cp ~/Downloads/knight.glb assets/imported/knight.glb
# 2. move to canonical place (keeps import .import file)
mv assets/imported/knight.glb assets/models/units/knight.glb
# 3. in Godot, select glb → Import → Meshes/Ensure Tangents, Materials/Location=Mesh + External
# 4. create material: assets/materials/thronefall/knight.tres → Shader = unit_thronefall.gdshader
# 5. WorldView will auto-pick glb if exists, else fallback to CapsuleMesh (see Assets.cs)
```

See `src/Core/Assets/Assets.cs` for runtime loader (`ResExists` → `GD.Load` → fallback).
