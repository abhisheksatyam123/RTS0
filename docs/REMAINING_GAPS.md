## Read this first: whole-game parity (refreshed 2026-10-08, evening)

The G1–G10 table below grades individual systems against 0 A.D.'s semantics, and `python3 tools/check_parity.py` reports 92% for them. Those scores are self-graded and only cover the systems listed. Judged by what a match actually plays like, RTS0 was **a little over half way** to 0 A.D. at that time (the open gaps now are in "Open gaps, re-check 3" below). That was an estimate from a code-only re-audit of main at `bff4f1c` (rechecked against `d8dd7af`, which adds a Gaia owner for defeated players' leftovers and sea fish) against 0 A.D.'s simulation components, UnitAI, session GUI, `config/default.cfg` hotkeys, game setup, gaia templates and renderer.

Content breadth moved up since the afternoon: 44 skirmish and scenario maps and 45 random map types, gates and structure upgrades, siege packing and siege garrisons, Petra diplomacy, tribute and trade toward every player, ship trade, and population cap, ceasefire, revealed map and allied victory in Game Setup. The estimate did not move because this audit read unit behaviour line by line, and found core 0 A.D. rules that earlier audits missed (the first list below). These matter more to how a match plays than the content that landed.

### Core behaviour gaps found 2026-10-08 (checked in code)

These were the biggest gaps between a RTS0 match and a 0 A.D. one, ordered by impact; all ten are fixed. The full list, including the session UI, menus, data and rendering, is under [Subsystem gaps](#subsystem-gaps-2026-10-08-audit).

1. ~~**A move order gets hijacked.**~~ Fixed by the unit orders PR: a plain move is UnitAI's WALKING and ignores enemies, attack-move is WALKANDFIGHT, and stance leash and range (`ShouldAbandonChase`, `GetQueryRange`) apply to targets a unit picks itself.
2. ~~**Hunting can't kill anything.**~~ Fixed by the fauna PR (U2): hunters kill animals and gather the carcass.
3. ~~**Citizen soldiers can't gather.**~~ Fixed by the gather PR (U3): citizen infantry and cavalry gather at their 0 A.D. class `Rates`.
4. ~~**Units idle when a resource runs out.**~~ Fixed by the unit orders PRs: a gatherer whose supply runs out takes the nearest one of the same kind (GATHER FINDINGNEWTARGET), and with none left drops its load off (`tools/test_unit_orders.cpp` 21, 29, 45). Women default to passive and flee 12 m from attackers.
5. ~~**Capture happens by standing near a building.**~~ Fixed by the unit orders PR: only units ordered to capture do so (Attack.js Capture, 4 m, once per second), and Ctrl+right-click attacks instead. No 0.28 template, tech or aura gives a structure capture resistance, so there is none to port.
6. ~~**Buildings can be placed anywhere.**~~ Fixed by the placement PR (U5): `check_placement` ports BuildRestrictions.js.
