## Checked, matches 0.28

- **Networked loading page.** Every peer switches to the loading page at Start, over the match while it loads (`mn:3455-3458`, `mn:3492-3499`, `mn:3524-3527`, as `GameSettingsController.js:286-305`). It shows "Generating “map”" or "Loading “map”" with the map's own name, a tip from a category weighted for multiplayer, a quote, and the progress bar with "Show 100 when it is really 99" (`scenes/menu/loading.gd:123-174`, as `gui/loading/TitleDisplay.js`, `ProgressBar.js:21-41`). "Waiting for players to connect:" follows it (`mn:946-966`).
- **Rated Game.** Offered only for a lobby game with two players, not for a saved game, and switched on by default when the player count or cheats change. Cheats are disabled while the game is rated, and "Rated game." or "Cheats enabled." is shown (`gs:2516-2546`, as `Rating.js`, `Cheats.js:22-31`, `GameSettingWarning.js`). The rating report and the replay menu's rated test follow `LobbyRatingReporter.Available` and `replay_menu.js:134-136`.
- **Cheats in multiplayer.** The host's setting, off by default. The sim refuses a cheat while it is off (`src/simulation/simulation.cpp:18163`, as Cheat.js). A cheat reaches the lockstep as a command, so everyone sees "(Cheat - …)" lines (`sn:104-108`). Defeated players and observers get nothing (`tm:1656-1657`).
- **Game speed in multiplayer.** Set only in the setup. Fast Forward is offered only while no client holds a seat (`gs:1405-1427`, as `GameSpeed.js:24-45`). There is no speed control in the match (`mn:3482-3489`, as `GameSpeedButton.js:10`, `GameSpeedControl.js:40-44`).
- **Allied View, Revealed and Explored Map** go to every peer in the setup string (`src/network/net_types.h:415`, `gs:1023`, `gs:2088`). New slots start as an AI with `gui.gamesetup.aidifficulty` / `aibehavior` (`gs:1356-1369`, as `PlayerAssignment.js:60-74`).
- **Out-of-sync box.** Turn, players, identical or differs, the AI rejoin warning after turn 1, mods, bug report and dump lines (`qc:22-31`, `qc:119-126`, as `OutOfSyncNetwork.js:12-48`), apart from gap 6.
- **Observer limit** applies only once the game runs, with reason 9 (`tm:594-598`, as `NS:1108-1120`).
- **Command validation.** Each command runs as the sender's seat on its own units (`tm:1641-1657`). An observer's batch is dropped at the host (`tm:1068`). Change perspective needs cheats (`tm:1645-1653`).
- **Replay list.** The Players column and player filter come from the replay's recorded names (`replay_browser.gd` `_entry`, as `replay_menu.js:323-326`). Multiplayer means more than one human (`replay_menu.js:130`).
- **Lobby details and profile.** Victory conditions, map type, size and description, host, "Game started at", "Players: n/m", teams and observers, mods with the incompatible heading (`ls:595-680`, as `GameDetails.js:58-125`). The profile rows are Current Rank, Highest Rating, Total Games, Wins, Losses and Win Rate (`lb:425-426`, as `ProfilePanel.xml:8-28`). The tooltips that 0.28 puts on incompatible and ignored mods are not shown (the RichTextLabel has none), which is cosmetic.
- **Session strings.** The quit questions, including "Leaving will disconnect all other players.", "I will return" and "I resign" (`qc:18`, `qc:40`). Reset Civs and Reset Teams for the host (`gs:1263-1290`).
- **Connect-flow strings not in RTS0.** "Connected to the server.", "Connection to the server has been authenticated." and the STUN and identifier errors belong to 0.28 paths that RTS0 replaces, as pass 5 and pass 7 noted.
