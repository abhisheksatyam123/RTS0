# RTS0 multiplayer vs 0 A.D. 0.28: sixth pass (setup defaults and limits, lobby joins, lobby lists, chat edges)

Read-only code audit, 2026-10-15. RTS0 is at `main` 2a98daed3 ("Merge remote-tracking branch 'origin/main' into claude/project-thread-d65cx1"), checkout `scratchpad/gmp2`, after pass 5 was closed by #1125. This pass leaves out everything that `audit-028.md` and passes 2 to 5 list as fixed or skipped on purpose, and everything already in their tables. Nothing was built or run. Each gap below was checked in both codebases by reading the code and grepping RTS0 for the 0.28 feature or its strings.

Before looking at behaviour, I ran a string sweep: 484 `translate()` strings and 75 XML captions and tooltips from the 0.28 lobby, prelobby, gamesetup, gamesetup_mp, session chat, session lobby, network overlays, message boxes and summary, each grepped in RTS0 `src/`, `scenes/` and `tools/`. Almost every player-facing string is present. The few misses were format templates that RTS0 builds another way, or text covered below. So the gaps that remain are about behaviour: a default, a capacity limit, how a join asks for a password, how often lobby lists refresh, and some edge cases.

## Checked, matches 0.28

- **Strings.** The sweep covered the 0.28 lobby, prelobby, gamesetup_mp, gamesetup, session chat, session lobby reporters, NetworkStatusOverlay, NetworkDelayOverlay, PauseOverlay, the session message boxes and the summary. Every player-facing sentence I found is in RTS0. This includes the lobby chat-command errors, the role and mute lines, subject changed or deleted, "Game started at", the "(OFFLINE)" game descriptions, "Rejoining Multiplayer games with AIs is not supported yet!", and the summary's Alt+L tooltip.
- **Setup network side.** Join, leave, ready and not-ready lines (`mn:2886-2905`). The `gamesetup.join` and `nick` sounds with their 3 s throttle (`mn:2926-2930`, `sl:1551-1556`). Tips hidden in multiplayer (`gs:1195`). Random biome and civs resolved at Start (`gs:2199`). Fast Forward speeds only while nobody holds a seat (`gs:1392-1413`). AI config read-only for clients (`gs:1579-1583`). Back's "Return to the lobby." or "Return to the main menu." (`gs:2328`). Ready captions and tooltips (`gs:2249-2251`).
- **Host authority.** A client's NMT_GAME_SETUP is ignored (`nh:992-998`, as `NS:1328-1349`). Each command runs as its sender's seat on the sender's own units (`tm:1617-1621`, as `NS:1196-1231`'s player check).
- **Session.** "Rated game" and "Cheats" in the match description (`scenes/session/game_description.gd:52`, `:176-178`). `closeOpenDialogs` on disconnect (`mn:869`). Disconnect reasons and their texts (`mn:870-885`). The "Waiting for players to connect:" list (`mn:930-936`). The summary's "You have been disconnected." (`scenes/session/summary_screen.gd:567-568`).
- **Lobby.** Game-list sorting, buddy marks and the double-click buddy toggle (`lb:243`, `:333`). Rating reports wait for every player of the match and drop reports that disagree, as EcheLOn does (`srv:472-501`). The lobby's mod mismatch box and the observe question (`lb:1585-1640`).
- **Options page.** Every 0.28 Networking / Lobby, Chat & Notifications, Sound and Game Setup key is present (`scenes/menu/options.gd`), except `lobby.tls`. That one is already noted in pass 5 as not player-visible.
- **Peer timeout.** I did not compare RTS0's 10 s silence drop (`nh:1178`) with 0.28's ENet default. 0.28 never calls `enet_peer_timeout` (grep in `src/0ad/network/`), and ENet's defaults scale with the round-trip time, so neither side is clearly stricter. Not listed.
